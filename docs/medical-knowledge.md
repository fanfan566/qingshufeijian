## 文件与运行

- `src/data/medicalKnowledgeCore.json`：核心解读数据，随代码维护并保留原有 AI 编码。
- `data/knowledge/catalog.json.gz`：约 4 MB 的离线术语快照，完整数据不进入前端 JavaScript 包。
- `data/knowledge/manifest.json`：来源、版本、原文件 SHA-256、统计信息及许可地址。
- `data/knowledge/NOTICE.md`、`licenses/`：数据归属及许可说明。
- `server/knowledgeCatalog.js`：Node 端解压、建立内存索引、检索和分页；进程内只加载一次。
- `src/data/knowledgeCategories.ts`：所有分类的统一颜色表，用于筛选、列表、详情和关联卡片。

保持原来的启动方式：根目录 `node server.js` 和 `npm run dev`。Vite 将 `/api/knowledge` 转发到 8001 端口。数据已打包入仓库，正常使用无需连接 HPO、MONDO、翻译网站或数据库，也不需要新增 Python 包。新增或更新数据快照后，需重启 Node 服务。

## API

- `GET /api/knowledge/metadata`：全库统计、分类统计、专题统计及来源版本。
- `GET /api/knowledge?q=哮喘&category=全部&scope=all&sort=relevance&page=1&pageSize=24`：中文、英文、同义词、标准编码及定义检索。
- `GET /api/knowledge/HP%3A0002099`：按编码获取完整定义、上位概念、外部编码和来源。

`scope` 支持 `all` / `respiratory`，`sort` 支持 `relevance` / `name`。页大小最多 100，前端提供 12 / 24 / 48 条，页码从 1 开始。非法参数返回 400，未知编码返回 404，数据文件故障返回 503。前端保留加载、失败重试、无结果及请求取消处理，详情按需加载。

## 重建与更新

Python 仅用于维护数据快照；应用运行无需执行导入脚本：

```sh
python scripts/import_medical_ontologies.py --download
```

脚本从固定版本和固定 Git 提交下载数据，保留 TLS 校验，校验每个原文件的固定 SHA-256，使用标准库解析 OBO / TSV，验证版本、记录数量、唯一编码后原子替换压缩快照。生成结果不包含当前时间，便于校验重建一致性。也可使用已有下载文件：

```sh
python scripts/import_medical_ontologies.py --source-dir /path/to/downloads
```

目录应包含 `hp`、`mondo`、`hp-zh.tsv`。更新上游版本时需同步修改脚本中的版本、地址、提交及经过可信下载核验的校验和，复核许可、过滤范围、中文映射与统计，并提交新快照及 manifest。不要伪造词条或用别名重复增加记录数。

## 结果关联与图片查看

`RelatedKnowledge` 只读取分析结果，不参与推理。保留原有 `label_code`、征象及旧接口类型映射。未知标签不作诊断猜测；亚实性结节不直接等同部分实性结节。

原图使用 `object-contain`，结果画布按原始宽高比显示；提示和统计位于图外。查看器支持缩放、拖动/滚动、适应窗口、Esc 关闭和焦点恢复。
