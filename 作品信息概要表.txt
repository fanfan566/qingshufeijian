## 二、作品简介

### 2.1 项目概述

"肺管家"是一个基于人工智能技术的肺部健康管理Web应用平台，集成了CT医学图像智能分析、AI健康咨询问答、个性化康复计划推荐、肺部疾病知识图谱和健康科普内容聚合等功能模块。系统旨在为用户提供专业、便捷的肺部健康监测与管理服务，辅助医生进行初步诊断，提升公众肺部健康意识。

### 2.2 核心功能

1. **CT图像智能分析**：支持上传肺部CT影像，自动进行肺部分割、结节检测、病变分类，并生成符合医疗规范的诊断报告
2. **AI智能问答**：基于通义千问大语言模型，提供7×24小时肺部健康咨询服务
3. **咨询反馈管理**：
   - 医患实时对话系统：支持医生与患者的多轮交互沟通，支持医生、患者、学生三种角色
   - 会话状态分类：稳定、需关注、重点跟进三个等级，实时展示患者病情表现
   - 智能建议同步：医生建议自动沉淀到患者私聊，便于患者查看和执行
   - 快速回复模板：为医生和患者预设常用回复，加速沟通效率
   - 搜索和筛选：支持按状态、关键词、患者ID、医生ID等多维度检索会话
   - 交互分析面板：实时统计建议数、互动频率、会话热度等关键指标
   - 多视图看板：Overview、Timeline、Actions三种视图，满足不同使用场景
4. **健康管理计划**：根据用户健康状况，智能推荐个性化康复训练计划并进行进度跟踪
5. **知识图谱可视化**：以图形化方式展示肺部疾病相关知识体系，便于用户理解和学习
6. **健康内容聚合**：通过爬虫系统从B站、丁香医生等平台获取优质健康科普内容

### 2.3 技术亮点

- 采用深度学习模型（lungmask + U-Net）实现高精度肺部分割
- 双后端微服务架构（Node.js + Python FastAPI），职责分离
- 混合爬虫方案，平衡内容质量与时效性
- 响应式设计，支持多终端访问

### 3.3 核心组件设计

#### 3.3.1 前端应用层（React）

**路由结构**：
- `/welcome` - 欢迎页面
- `/segmentation` - CT图像分割分析页面

- `/plan` - 健康管理计划页面
- `/consultation-feedback` - 医患咨询反馈页面
- `/crawler-status` - 爬虫爬取状态监控

**状态管理**：使用React Hooks + Context API管理全局状态，包括用户信息、会话数据、分析结果缓存

#### 3.3.2 认证授权模块（Node.js）

**工作流程**：
1. 用户注册：密码使用bcrypt加密存储
2. 用户登录：验证后返回JWT令牌，有效期7天
3. 令牌刷新：前端在令牌过期前自动续期
4. 权限控制：中间件验证请求中的JWT，提取用户角色信息

**接口规范**：
```
POST /api/auth/register  - 注册新用户
POST /api/auth/login     - 用户登录
POST /api/auth/refresh   - 刷新token
GET  /api/user/profile   - 获取用户信息
```

#### 3.3.3 AI分析服务（Python FastAPI）

**处理流程**：
1. 接收上传的医学图像（DICOM/PNG/JPG）
2. 使用pydicom库或OpenCV解析图像
3. 调用lungmask模型进行肺部分割
4. 计算分割统计指标（面积、体积、左右肺比例）
5. 返回分割掩码和统计结果

**关键接口**：
```
POST /segment      - 上传图像并进行肺部分割
GET  /models/info  - 获取模型版本信息
GET  /health       - 服务健康检查
```

#### 3.3.4 模型集成层

**lungmask模型**：
- 输入：医学图像（512×512或1024×1024像素）
- 输出：二值掩码（背景=0，肺部=1）
- 模型大小：约200MB，使用GPU时内存占用<2GB

**U-Net模型**：
- 用于更细致的肺叶分割
- 可选模型，用于高精度分析场景

#### 3.3.5 数据通信规范

**请求格式**：
```json
{
  "action": "segment",
  "imageData": "base64编码的图像",
  "mimeType": "image/png",
  "userId": "用户ID"
```

## 四、主要功能模块说明

### 4.1 CT图像分析模块

**功能描述**：用户上传肺部CT图像后，系统自动执行以下分析流程：

**完整工作流程**：
```
用户上传图像
    ↓
前端验证（格式、大小）
    ↓
base64编码上传至FastAPI服务
    ↓
图像预处理（标准化、裁剪）
    ↓
lungmask模型分割
    ↓
统计分析（面积、比例）
    ↓
结果校验（异常检测）
    ↓
生成诊断报告
    ↓
返回到前端展示
```

**功能详解**：
1. **肺部分割**：使用lungmask预训练模型精确分割左右肺区域，输出二值掩码
2. **统计分析**：计算肺部面积、占比、左右肺比例等指标
   - 肺部面积占比：正常范围40%-70%
   - 左右肺面积比：正常范围0.55-1.45
3. **异常检测**：校验分割结果有效性，检测明显异常（如一侧肺占比超60%）
4. **结节检测**：识别疑似肺结节病灶，标注位置和大小
5. **病变分类**：判断肺炎、COPD、肺气肿、纤维化等病变类型
6. **报告生成**：自动生成包含BI-RADS分级的诊断报告

**数据结构**：
```python
class SegmentationResult:
    lungs_area: float           # 肺部总面积（像素数）
    lungs_percentage: float     # 肺部占图像面积的百分比
    left_lung_area: float       # 左肺面积
    right_lung_area: float      # 右肺面积
    left_right_ratio: float     # 左右肺面积比
    confidence: float           # 分割置信度（0-1）
    abnormal_flags: List[str]   # 异常标记列表
    mask_image: np.ndarray      # 分割掩码图像
    processing_time: float      # 处理耗时（秒）
```

**技术指标**：
- 支持格式：PNG、JPG、DICOM
- 分割精度：Dice系数 > 0.95
- 处理时间：< 10秒（单张2D图像）
- 支持批量处理：可一次上传多张图像

**错误处理**：
- 文件格式错误：返回400错误提示
- 图像过大：自动压缩至1024×1024
- 模型加载失败：自动重试或使用备用模型
- 分割失败：返回详细错误信息并建议用户重新上传

### 4.2 AI智能问答模块

**功能描述**：基于通义千问大语言模型，提供肺部健康相关咨询服务

**工作流程**：
```
用户输入问题
    ↓
前端获取用户历史对话（上下文）
    ↓
发送请求至Node.js后端
    ↓
后端调用通义千问API
    ↓
API返回回复文本
    ↓
后端格式化处理
    ↓
存储对话记录至数据库
    ↓
返回到前端流式展示
```

**功能特点**：
- **角色设定**：系统提示设定为"肺部健康助手"，确保回答的专业性和准确性
- **对话历史**：保留最近10条对话作为上下文，提高回答连贯性
- **错误降级**：主API失败时自动切换到备用Gemini API
- **流式响应**：支持实时流式输出，提升用户体验
- **多轮对话**：支持用户与AI进行连续的、有上下文的多轮对话

**调用接口**：
```
POST /api/chat/ask
{
  "message": "用户问题",
  "conversationId": "会话ID",
  "context": [历史对话...]
}

响应：
{
  "code": 0,
  "data": {
    "response": "AI回复",
    "conversationId": "会话ID",
    "timestamp": "时间戳"
  }
}
```

**模型配置**：
- 模型名称：qwen-plus (阿里云通义千问)
- 温度参数：0.7（平衡创意性与准确性）
- 最大tokens：2048
- API密钥：从环境变量读取

**内容安全**：
- 输入检查：过滤医学禁用术语
- 输出规范：添加免责声明"仅供参考，不作为医学诊断"
- 敏感词过滤：自动识别并处理

### 4.3 健康管理计划模块

**功能描述**：根据用户健康状况和医生建议，推荐个性化康复计划

**计划类型**：

1. **呼吸训练计划**
   - 腹式呼吸训练：每日3次，每次15分钟
   - 缩唇呼吸：改善气道通畅度
   - 咳嗽训练：清除气道分泌物

2. **运动康复方案**
   - 有氧运动：快走、太极（30分钟/次）
   - 力量训练：上肢和核心肌群锻炼
   - 柔韧性训练：瑜伽、拉伸

3. **饮食建议**
   - 营养补充：蛋白质、维生素、矿物质
   - 禁忌提醒：刺激性食物、烟酒
   - 水分摄入：建议每日2升以上

4. **生活习惯指导**
   - 作息规律：建议晚上11点前入睡
   - 环境改善：避免污染、保持通风
   - 心理调适：压力管理、情绪调节

**推荐引擎**：
```
分析用户信息：年龄、性别、身体状况、历史诊断
    ↓
匹配肺部疾病库：结节、炎症、气肿等
    ↓
生成个性化计划：难度递进式设计
    ↓
设置提醒机制：日程提醒、完成统计
    ↓
跟踪进度：记录用户完成情况
    ↓
动态调整：根据反馈优化计划
```

**进度跟踪功能**：
- 完成率统计：每周、每月汇总
- 成就系统：达成里程碑时获得徽章
- 数据可视化：生成进度图表
- 医生评价：医生可对计划执行情况打分

### 4.4 知识图谱可视化模块

**功能描述**：以可视化方式展示肺部疾病相关知识体系

**知识库内容**：
- **疾病节点**：100+种肺部疾病（肺炎、COPD、肺纤维化等）
- **症状节点**：咳嗽、胸痛、呼吸困难等
- **检查方法**：CT、X光、支气管镜等
- **治疗方案**：药物、手术、康复等

**可视化技术**：
- **力导向图**：使用D3.js绘制节点关系网络
- **交互功能**：点击展开详情、拖动探索、缩放视图
- **配色方案**：不同类型节点使用不同颜色区分
- **响应式设计**：支持移动端查看

**查询功能**：
```
输入疾病名称
    ↓
搜索知识图谱
    ↓
突出相关节点
    ↓
展示关联信息
    ↓
提供学习路径（从症状→诊断→治疗）
```

**学习路径示例**：
- 症状路径：胸痛 → CT检查 → 肺炎诊断 → 抗生素治疗 → 康复指导
- 疾病路径：COPD → 病因（吸烟） → 症状 → 检查 → 治疗 → 预防

### 4.5 健康内容爬虫模块

**功能描述**：从多个健康平台聚合优质科普内容

**数据来源**：

1. **B站视频爬虫**
   - 搜索关键词：肺部健康、呼吸训练、康复视频等
   - 提取信息：视频标题、UP主、播放量、评分、链接
   - 更新机制：每6小时自动爬取最新视频

2. **丁香医生爬虫**
   - 爬取文章列表：肺部疾病知识、预防指南
   - 信息提取：标题、发布时间、作者、内容摘要
   - 链接验证：确保链接有效性

3. **RSS订阅源**
   - 权威来源：WHO、CDC、中国健康教育中心
   - 医学期刊：lung相关学术期刊摘要
   - 自动更新：定期检查新发布内容

**爬取工作流**：
```
定时任务触发（6小时间隔）
    ↓
连接目标网站
    ↓
解析HTML或API
    ↓
提取关键信息
    ↓
数据清洗：去重、验证
    ↓
存储至本地缓存
    ↓
更新前端内容库
```

**内容质量控制**：
- **白名单机制**：只爬取预先审核的高质量源
- **内容过滤**：排除广告、低质量内容
- **手动维护库**：核心推荐内容由人工精选
- **用户评价**：根据用户反馈调整推荐优先级

**内容展示**：
```
JSON结构：
{
  "id": "content_id",
  "type": "video|article|news",
  "title": "内容标题",
  "summary": "内容摘要",
  "source": "b站|丁香医生|RSS",
  "sourceUrl": "原始链接",
  "publishDate": "发布时间",
  "imageUrl": "缩略图",
  "viewCount": 观看数,
  "rating": 评分,
  "tags": ["标签1", "标签2"]
}
```

**推荐算法**：
- 内容热度：基于播放量、评分、用户点击
- 相关性：与用户浏览历史、诊断结果匹配度
- 时效性：优先推荐最新发布的内容
- 多样性：避免重复推荐同一类型内容

**错误处理**：
- 网络超时：自动重试3次
- 页面变更：使用备用爬虫策略
- 反爬虫检测：使用随机UA和延时请求
- 爬虫失败：记录日志并人工检查

## 五、创新点

1. **多模态AI融合**：结合计算机视觉（图像分析）和自然语言处理（智能问答），提供全方位健康服务

## 八、使用说明

### 8.1 快速启动

1. 安装依赖：
   ```bash
   npm install
   cd backend && pip install -r requirements.txt
   ```

2. 配置环境变量：复制`.env.example`为`.env`，填写API密钥

3. 一键启动：双击运行`一键启动.bat`

4. 访问系统：浏览器打开 http://localhost:5173

### 8.2 主要操作流程

1. 登录后进入"图像分析"页面
2. 上传肺部CT图像（PNG/JPG格式）
3. 点击"开始分析"按钮
4. 查看分割结果和统计指标
5. 下载诊断报告

**智能问答**：
1. 进入"健康咨询"页面
2. 输入健康问题
3. 查看AI回复，可进行多轮对话

**查看推荐内容**：
1. 进入"健康资讯"页面
2. 浏览推荐的视频和文章
3. 点击链接跳转至原平台观看
