本文件夹作用：
本文件夹为医学图像分析后端目录，主要用于提供基于 FastAPI 的肺部 CT 图像分析能力，包含后端应用入口、接口定义、模型代码、数据目录、日志目录、脚本目录及相关说明文档。

本文件夹内主要文件说明：
1. README.md
   后端项目说明文档，介绍后端功能、目录结构、启动方式、API 端点和技术栈。

2. DEPLOYMENT.md
   后端部署说明文档，用于记录部署流程、运行要求或上线配置要点。

3. requirements.txt
   Python 依赖列表文件，用于安装后端运行所需库。

4. train_unet.py
   与 U-Net 模型训练相关的脚本文件。

5. verify_lungmask.py
   用于校验或测试肺部分割能力的脚本文件。

6. test_mask_result.png
   后端图像处理或分割测试结果示例图片。

本文件夹内主要子文件夹说明：
1. app/
   后端核心应用目录，包含配置、应用入口、接口、模型、服务和工具代码。

2. data/
   后端使用的数据目录，通常用于存放模型文件、上传数据或处理中间数据。

3. logs/
   后端运行日志目录，用于保存系统运行日志和调试信息。

4. scripts/
   后端辅助脚本目录，用于存放部署、下载模型或批处理类工具脚本。
